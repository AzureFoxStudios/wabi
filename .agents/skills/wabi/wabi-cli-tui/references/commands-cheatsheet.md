# wabi-tui command cheatsheet

## Screens
1 Chat · 2 Users · 3 Server · 4 Logs · Tab cycle

## Global
`:` command · `l` login · `r`/F5 refresh · `?` help · `q` quit

## Commands
`:chat` `:users` `:server` `:logs`  
`:filter` `:ufilter` `:goto` `:refresh` `:logout` `:help`  
`:fps N` `:poll N` `:eink` (2 fps + 8s poll)

## Config / env
`fps`, `poll_secs` in `~/.config/wabi/config.toml`  
`WABI_TUI_FPS`, `WABI_TUI_POLL_SECS`

See also `references/eink-fps-and-poll-2026-08-06.md`.
