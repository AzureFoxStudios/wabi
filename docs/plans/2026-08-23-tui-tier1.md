# Wabi TUI — Tier 1 Foundation (2026-08-23)

Goal: bring `core/crates/wabi-tui` (2026-08-06 vintage) up to the server's
current live-transport + channel model. Task list only, no estimates.

## Wire contract (verified against source)

- Live transport = **Socket.IO** (`socketioxide` in wabi-server, `socket.io-client`
  in frontend). Raw `/ws` (`websocket.rs`) is call-signaling only.
  - Handshake: `auth: { token: <jwt> }`; invalid → `auth-failed` + disconnect.
  - After connect: `emit("join", username)`, then `emit("join-channel", channel_id)`
    per open channel room.
  - Inbound `"message"` event payload: `{ channelId, message }`, where `message`
    is the message_view: `id, user, userId, senderStableId, color, text,
    timestamp, bornAt, type, clientMessageId, isSpoiler, replyTo, files, ...`.
  - Also available: `typing` (emit) / user-typing, `edit-message`,
    `delete-message` → `message-deleted`, `toggle-pin-message` →
    `message-pinned`, `add-emoji-reaction` / `remove-emoji-reaction`.
- Channel types on the wire (`api/channels.rs::channel_kind_to_type`):
  `text | dm | group | voice | lore | whiteboard | announcement` (+ legacy
  asset_storage→lore mapping).
- REST history fallback unchanged: `GET /api/messages/{channel_id}?limit=N`.

## Tasks

- [ ] Parse `channel_type` into a typed enum in `api.rs::Channel`.
- [ ] Channel list UI: type badge per row (`#text`, `@dm`, `👥group`,
      `🎤voice`, `📚lore`, `🖼whiteboard`, `📣announcement`).
- [ ] DM/group channels pinned to a top section of the channel pane.
- [ ] Non-text channels selectable but render a stub detail ("surface not yet
      in TUI") instead of silently showing text messages.
- [ ] Keep flat ordering stable within sections (position, then name).

### Slice B — Socket.IO live feed
- [ ] Add `rust-socketio = ">=0.6,<0.7"` (verify latest on crates.io; pin per
      dependency policy with upper bound).
- [ ] New `live.rs`: owns the socket.io client connection; maps inbound events
      to existing `BgMsg` variants over `bg_tx` (no new channel plumbing).
      - `LiveMsg { channel_id, message }` → append to open buffer +
        unread counter for background channels.
      - `LiveTyping { channel_id, username }` → status line indicator
        (3s expiry).
      - Connect/disconnect/reconnect events → log line + poll re-enable.
- [ ] On login success: spawn connect task with JWT; emit `join` + current
      `join-channel`. On channel switch: emit `join-channel` for new room.
- [ ] Demote 3s poll: keep as reconnect safety net only (runs when socket is
      down or after missed-event detection), not steady-state.
- [ ] Send path: keep REST POST for v1 (server persists + broadcasts); switch
      to socket `message` emit later if round-trip latency matters.
- [ ] Unread toast line when message lands in non-focused channel.

- [ ] `cargo build -p wabi-tui --release` clean.
