## How to use this roadmap

When starting work on a card, move it from `📋 TODO` to `🛠️ IN PROGRESS` and create a plan file at `docs/plans/2026-MM-DD-card-XYZ.md`. When the card is verified, move it to `✅ DONE`.

Blockers should be annotated with `⚠️ BLOCKED` and a brief reason.
