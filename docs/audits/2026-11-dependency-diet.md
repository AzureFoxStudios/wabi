tarball (see §6), the frontend suite was run in a reproducible temp harness:
copy `frontend/` → temp dir, remove **only** the `xlsx` lockfile/dependency
entry, `npm ci --ignore-scripts`, install a minimal local `xlsx` stub, copy
repo-root `shared/` to the corresponding temp parent so
`../../../../shared/...` imports resolve. Both **HEAD (before)** and **patched
(after)** trees were run through the identical harness.
