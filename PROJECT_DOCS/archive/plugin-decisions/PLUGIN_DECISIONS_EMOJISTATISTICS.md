# Plugin Decisions - EmojiStatistics

## 2026-02-28
### Decision: Keep EmojiStatistics local-only
- Reason:
  - The primary value is immediate catalog visibility in settings.
  - Backend aggregation is unnecessary for MVP and increases complexity.
- Consequence:
  - Stats reflect only the current local emoji inventory.

### Decision: Do not emit telemetry for emoji stats
- Reason:
  - This is a static, user-facing summary; no operational metrics are required.
  - Keeps privacy posture simple and explicit.
- Consequence:
  - No network requests or analytics payloads are generated by this feature.

### Decision: Bound category output to top entries
- Reason:
  - Prevents settings UI clutter for large emoji catalogs.
- Consequence:
  - Only the top category slice is shown; full raw lists are not rendered in Add-ons.
